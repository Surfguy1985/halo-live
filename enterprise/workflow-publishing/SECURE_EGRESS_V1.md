# Secure outbound egress v1 (draft, off by default)

This is an actual Node HTTPS transport implementation behind the existing hardened transport interface, but there is **no executable worker wiring and no destination configured**. It performs a trusted-host exact HTTPS check, resolves all DNS answers, denies non-public/reserved IPv4 and all IPv6 answers, pins the selected public IP using an explicit HTTPS lookup callback, uses the requested hostname for TLS identity validation, disables connection pooling, rejects redirects and unauthorized headers, caps request/response bytes, and applies a timeout.

The test suite uses injected fake DNS/request functions; the public-network behavior and real TLS handshake have **not** been integration-tested. Production requires a stronger OS-level network egress boundary preventing proxy and socket bypass, a complete IANA special-use address review, DNS/TLS integration tests, per-stage timeouts including slow-drip total deadline, network connection abort tests, metrics, and a security review. Real delivery must be bound to permit consumption, authorized tenant/consumer registry, signing secrets and revocation policy. No Enforcer, Base44 or production changes.
