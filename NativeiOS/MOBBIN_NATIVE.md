## HALO design rules
1. One primary action per state.
2. Job context stays visible while executing work.
3. Camera is a workflow action, not a media library.
4. Field users never need to understand the office data model.
5. Turns and Maintenance share the same interaction grammar.
6. Every offline action must feel completed locally and sync later.
7. Use SF Symbols, Dynamic Type, native sheets, haptics, MapKit and Live Activities before custom substitutes.
